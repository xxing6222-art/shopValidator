# 勇哥判店 · 先判断，再投钱

勇哥判店帮你在签约、装修、借钱或继续追加投入之前，先花十分钟把一家餐饮店“该开、该改，还是该停”想清楚。

- 生产站点：<https://shopvalidator.zhangyvjing.com>
- 演示站点：<https://demo.shopvalidator.zhangyvjing.com>

## 它是什么

它不是“问 AI 该不该开店”的聊天框，而是一套按固定流程走的经营决策检查：先确认门店位置，再用一次持续语音问诊，把你口中含糊的营业额、房租、人工、毛利，变成可以核对的经营事实，最后给出带预算、指标、成功线和停止线的下一步方案。

未知就是未知——它不会把“不知道”当成 0，也不会把一个范围偷偷写成精确数字。证据不够时，它会先让你补证据，而不是编一个看起来精确的答案。

## 怎么用

四步，大约十分钟：

1. **确认位置** —— 确认门店所在的地址与商圈背景。
2. **语音问诊** —— 点一次“开始问诊”，然后像聊天一样把情况说出来，系统自动逐题推进。
3. **核对事实** —— 在一页里确认、标记未知，或直接改写系统听到的每一条事实。
4. **看判断与方案** —— 得到“继续 / 小步验证 / 停止 / 退出”的判断，以及可执行的下一步。

看完自己的店，往下滑还能看到别人的店是怎么被判断的。

问诊有 **6 个核心问题**，系统最多再自适应追加 **3 个补证据问题**，**12 轮为安全上限**，不会没完没了地问下去。

## 判断是怎么得出的

一次判断由**多个 AI Agent 并行完成**：先把账算清，再并行生成多条候选方案，每条方案都要经过“证据与因果”“财务与执行”两道核验才会留下。当前一次分析约用到 9 个 Agent，架构上可扩展到数十个（五六十个）并行工作。完整分析不设每日或按网络地址的次数上限。

判断维度来自真实案例校准：整理 623 个公开餐饮案例，筛选 156 份高可信字幕提取判断维度。

## 演示模式

演示站复用同一套四步界面，自动播放一条真实字幕案例（山西运城稷山县私房小碗菜）从问诊到判断的完整过程。演示只用于讲解产品，结果明确标注为案例演示，不能当作对现实门店的经营意见。
